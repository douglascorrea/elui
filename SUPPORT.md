# Support

Elui is an early-stage open-source project.

## Questions

Open a GitHub issue with the `question` label and include what you are trying
to build, your Elixir/OTP version, and the terminal emulator you are using.

## Bugs

Use the bug report template and include:

- Elixir and OTP versions
- Operating system and terminal emulator
- Minimal code or an example command
- Expected behavior
- Actual behavior

## Security

For security reports, follow [SECURITY.md](SECURITY.md). Do not open public
issues for vulnerabilities.
